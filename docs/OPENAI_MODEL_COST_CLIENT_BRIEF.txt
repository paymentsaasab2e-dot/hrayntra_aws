NOTES FOR CLIENT
----------------
• All prices below are USD per 1 million tokens unless stated otherwise.
• "Input" = text/audio you send to the model. "Output" = text the model returns.
• "Cached input" = repeated context (same instructions/history) billed lower.
• ChatGPT subscription is separate — this document is for API usage in the product.
• Today the live codebase mostly uses gpt-4o-mini (cheapest). This brief compares
  upgrading to gpt-4.1 vs gpt-4o for quality.

• Voice (mock interview microphone): browser speech is FREE today. OpenAI voice
  APIs are NOT wired yet. If added later, see Section 4 (voice add-on).

--------------------------------------------------------------------------------
WHEN TO CHOOSE GPT-4o (vs 4.1 or 4o-mini) — QUICK GUIDE
--------------------------------------------------------------------------------

  Use gpt-4o when:
    • Mock interview / practice chat needs the most human-like tone
    • CRM floating assistant must follow complex instructions + tools
    • You may add image/PDF vision on resumes or screenshots later
    • Client wants "premium AI" quality on candidate-facing features

  Use gpt-4o-mini instead when:
    • High volume, low risk (typeahead, simple suggestions, Aria at scale)
    • Cost is the main constraint

  Use gpt-4.1 instead when:
    • Heavy JSON/schema output (JD forms, lead optimize) at lower $ than 4o
    • Output token cost matters more than dialogue naturalness

SECTION 3 — COMPARISON: WHICH IS BEST vs CHEAPEST FOR OUR USE CASES
================================================================================

CURRENT PRODUCTION DEFAULT (in code today)
------------------------------------------
  Model: gpt-4o-mini
  Standard price: $0.15 in | $0.075 cached | $0.60 out (per 1M tokens)
  ~13× cheaper on input and ~13× cheaper on output vs gpt-4.1
  Best for: high volume, typeahead, simple suggestions, cost control
  Trade-off: weaker JSON/tool accuracy vs gpt-4.1 / gpt-4o

SIDE-BY-SIDE (Standard, per 1M tokens)
--------------------------------------
  Model          | Input  | Cached in | Output | Best for our platform
  ---------------|--------|-----------|--------|------------------------------------------
  gpt-4o-mini    | $0.15  | $0.075    | $0.60  | CHEAPEST — keep for bulk/low-risk AI
  gpt-4.1        | $2.00  | $0.50     | $8.00  | BEST VALUE quality upgrade
  gpt-4.1-mini   | $0.40  | $0.10     | $1.60  | Middle tier — parsing at lower cost
  gpt-4o         | $2.50  | $1.25     | $10.00 | BEST dialogue + multimodal future
  gpt-4o-mini    | (same as row 1)     |        | (duplicate — cheapest chat)

RECOMMENDATION FOR CLIENT (practical rollout)
---------------------------------------------

  TIER A — CHEAPEST (status quo)
    Use: gpt-4o-mini everywhere possible
    Phase 1 + Phase 2: matching helpers, Aria, services suggest, high-volume chat
    Est. relative cost: 1× (baseline)

  TIER B — BALANCED (recommended production mix)
    Use: gpt-4o-mini for light tasks
    Use: gpt-4.1 for resume parse, JD/lead JSON, assistant tools, match narratives
    Embeddings: text-embedding-3-large for match quality
    Est. relative cost: ~3–8× vs Tier A (depends on how many calls use 4.1)

  TIER C — HIGHEST QUALITY
    Use: gpt-4o for mock interview, assistant, and anything needing best UX tone
    Use: gpt-4.1 for heavy JSON parsing (optional split)
    Est. relative cost: ~4–10× vs Tier A

  WINNER BY CATEGORY
    Cheapest overall:        gpt-4o-mini (current default)
    Best quality per dollar: gpt-4.1 (structured work + lower output $ than 4o)
    Best conversation UX:    gpt-4o (interview bot, assistant chat)
    Best job similarity:     text-embedding-3-large (not a chat model)

  SIMPLE CLIENT MESSAGE
    "We can keep costs low with gpt-4o-mini for routine AI. For resume parsing,
     CRM assistant, and match explanations, gpt-4.1 offers the best balance of
     accuracy and price. gpt-4o is the premium option for natural interview
     dialogue and future image/document vision."
